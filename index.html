About ECLIPSE Launcher

ECLIPSE Launcher is a custom desktop launcher being developed for the ECLIPSE Cobblemon community server. Its purpose is to provide players with a simple way to authenticate, access their legitimate Minecraft Java Edition profile, prepare the required game files, and join the ECLIPSE server.

Desktop launcherCobblemon communityMinecraft Java Edition

Microsoft & Minecraft authentication

The launcher is designed to use Microsoft's official OAuth authentication flow. ECLIPSE Launcher does not ask users to enter their Microsoft password inside the launcher and does not store Microsoft passwords.

The project requires access to Minecraft Services in order to verify legitimate Minecraft Java Edition ownership and retrieve the authenticated player's Minecraft profile information, including UUID, username and skin.

Licensing and security

ECLIPSE Launcher is not intended to bypass Microsoft or Minecraft authentication, ownership, entitlement, licensing, or safety checks. A valid account and the required game entitlement are expected before game launch.

The desktop application is implemented as a public client and does not embed a confidential client secret.

Project status

ECLIPSE Launcher is currently under development. Authentication and Minecraft profile integration are being completed before public release.
